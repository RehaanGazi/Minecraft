Server Info

IP
play.blockyworld.net

The server runs the latest stable version and resets the map every few months so nobody's old dirt hut becomes a permanent eyesore. Whitelisting is off, so anyone can hop in. There's a small set of rules: no griefing, no lag machines, and no building right next to spawn if you can help it. Other than that, do whatever you want with your blocks.

Made for fun while learning CSS. Not affiliated with Mojang or Microsoft.
